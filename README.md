# Turtle Actions Showcase

This project demonstrates every public action available on `turtle.Turtle`
(including aliases) with a logger-friendly wrapper that works even in headless
Python environments. All tools rely solely on the Python standard library and
switch to **DRY-RUN** mode automatically when `_tkinter` or a display is not
available.

## Included tools

| Script | Purpose |
| --- | --- |
| `turtle_actions.py` | Core library that wraps a single `turtle.Turtle`, exposes one public method per action, and gathers documentation metadata. |
| `demo_all_actions.py` | Hands-off demo that iterates through every action, logs query results, binds event handlers, and generates `turtle_actions_reference.md`. |
| `turtle_ui.py` | Minimal Tkinter control panel with play/pause, step, reset, speed, and live log output. |
| `turtle_console.py` | Lightweight debugging REPL with optional session recording. |
| `make_notebook.py` | Builds `turtle_actions_notebook.ipynb` without external dependencies. |
| `turtle_actions_reference.md` | Markdown cheat sheet generated by the demo. |

### Quickstart

```bash
python demo_all_actions.py       # run the scripted demonstration
python turtle_ui.py              # open the control panel UI
python turtle_console.py         # launch the interactive REPL
python make_notebook.py          # generate the companion notebook
```

### Scripts section

The `scripts/` directory is not required; instead, run the commands above
from the repository root. Logs from the REPL are written to `logs/` and
ignored by Git.

## Actions covered

- Motion: `forward`, `fd`, `backward`, `bk`, `back`, `right`, `rt`, `left`, `lt`, `goto`, `setpos`, `setposition`, `teleport`, `setx`, `sety`, `setheading`, `seth`, `home`, `circle`, `dot`, `stamp`, `clearstamp`, `clearstamps`, `undo`, `speed`
- State: `position`, `pos`, `towards`, `xcor`, `ycor`, `heading`, `distance`
- Measurement: `degrees`, `radians`
- Pen (drawing): `pendown`, `pd`, `down`, `penup`, `pu`, `up`, `pensize`, `width`, `pen`, `isdown`
- Pen (color): `color`, `pencolor`, `fillcolor`
- Pen (fill): `filling`, `begin_fill`, `end_fill`
- Pen (more): `reset`, `clear`, `write`
- Visibility: `showturtle`, `st`, `hideturtle`, `ht`, `isvisible`
- Appearance: `shape`, `resizemode`, `shapesize`, `turtlesize`, `shearfactor`, `tiltangle`, `tilt`, `shapetransform`, `get_shapepoly`
- Events: `onclick`, `onrelease`, `ondrag`
- Specials: `begin_poly`, `end_poly`, `get_poly`, `clone`, `getturtle`, `getpen`, `getscreen`, `setundobuffer`, `undobufferentries`

## Headless environments

If `_tkinter` cannot be imported or a display is unavailable (for example on
most CI servers), the wrapper switches to DRY-RUN mode. All scripts continue to
work and print their call history, while the UI keeps its controls active and
streams log messages even without a live turtle canvas. The `teleport` action is
only available on Python 3.12 or newer; older runtimes raise a clear error when
it is invoked.
